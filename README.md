# Voice Activated Personal Assistant

# Introduction

This project is a simple voice activated personal assistant developed using Python.

The assistant accepts commands through the microphone and responds using speech.

# Features

- Voice recognition
- Text to speech
- Weather information
- News headlines
- Reminder
- Exit command

# Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- Requests
- Feedparser
- OpenWeatherMap API

# How to Run

Install the required libraries:

pip install -r requirements.txt

Run the program:

python main.py

# Example Commands

Hello

What is the weather?

Read the news

Set a reminder

Exit
